# Supabase Final Steps

1. Open the Supabase SQL Editor: https://supabase.com/dashboard/project/bdgdvukotgrytactwses/sql
2. Open `artifacts/kenya-is-nepal/supabase/schema.sql`, paste it into the SQL Editor, and run it.
3. In Supabase Authentication → Users, create the administrator account using `admin@kenyaisnepal.org`. Enter the administrator password privately in the Supabase form; it is intentionally not written here.
4. In Storage, create a bucket named `kenyaisnepal` and make it public.
5. Verify the deployed `/setup` page after the schema and bucket are ready.
