# Kenya Is Nepal — New Account Recovery

1. Download the project ZIP.
2. Create or open a new Replit account.
3. Upload the ZIP and extract it into the project root.
4. Run `pnpm install && pnpm --filter @workspace/kenya-is-nepal run build`.
5. Push the clean project to `joelmaina1998/kenya-is-nepal` with the GitHub connection or your own authenticated Git client.
6. In Vercel, import `joelmaina1998/kenya-is-nepal`, set Root Directory to `artifacts/kenya-is-nepal`, add the four environment variables through the secure dashboard, and deploy.
7. Add `kenyaIsNepal.org` in Vercel Domains and complete the DNS instructions.

Never paste secret values or the administrator password into GitHub, this ZIP, shell history, or chat. Use the secret-entry forms in Replit and Vercel.
